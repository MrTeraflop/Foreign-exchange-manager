# 英镑汇率监控

每天北京时间 7:00～23:00，每 30 分钟检查一次中国银行**英镑现汇卖出价**（每 100 英镑兑人民币），跌破设定价位时通过 ntfy 推送到手机。

## 提醒规则

- 提醒线依次为：阈值、阈值 − 步长、阈值 − 2×步长……（例如 890、888、886……）
- 价格第一次低于阈值时提醒一次，之后每跌破下一条线再提醒一次。
- 一次跌破多条线只发一条提醒。
- 价格回到阈值及以上时重置；小幅反弹再跌回去不会重复提醒。
- 连续抓取失败达到设定次数时提醒一次，恢复后再推送一条恢复通知。

## 修改设置

仓库 **Settings → Secrets and variables → Actions → Variables** 标签：

| 变量名 | 含义 | 不设置时的默认值 |
|---|---|---|
| `ALERT_THRESHOLD` | 提醒阈值（每 100 英镑兑人民币） | 890 |
| `ALERT_STEP` | 跌破后每再降多少提醒一次 | 2 |
| `FAIL_ALERT_COUNT` | 连续抓取失败几次后提醒 | 3 |

点变量右侧的铅笔图标即可修改，下一次检查自动生效。

ntfy 频道名保存在 **Secrets** 标签下的 `NTFY_TOPIC`。

## 手动运行

**Actions** → 左侧 **英镑汇率监控** → **Run workflow**：

- `test`：抓一次价格，发一条测试推送（不影响提醒记录）。
- `check`：立即正式检查一次，不受时段限制。

## 暂停 / 恢复

**Actions** → **英镑汇率监控** → 右上角 **⋯** → **Disable workflow**（暂停）或 **Enable workflow**（恢复）。

## 文件说明

- `monitor.py`：抓取与判断脚本（只用 Python 标准库）。
- `.github/workflows/monitor.yml`：定时运行配置。
- `state.json`：程序自动维护的记录（上次价格、已提醒到哪条线），不需要手动修改。
